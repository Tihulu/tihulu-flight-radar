Internet layers — select individually or combine

General flights: Combine mode queries selected networks, then removes duplicate ICAO24 aircraft. OpenSky is subject to daily API quotas and adsb.fi is for personal, non-commercial use. Other providers may temporarily be blocked by CORS or rate limits. On GitHub Pages, real adsb.lol aircraft load automatically without an antenna or local app, through an independent public cors.dev relay because its API does not permit direct GitHub Pages requests. The relay receives your browser IP and an approximately 10 km-rounded map center, never raw USB IQ; it may be rate-limited or unavailable. Data © adsb.lol (ODbL 1.0). Select IntelSky for direct, keyless but limited military/government coverage; AirLabs requires your own key. Your SDR continues independently if any Internet service fails.

Optional: paired receiver / Internet feed settings (advanced)

AirLabs keys are sent to AirLabs in a request URL and are visible in browser developer tools. Never embed a shared key in GitHub Pages. Free API plans have limited quotas; this app retains no key after the tab closes.

Browser-first radar: choose RTL-SDR above for direct WebUSB reception, or use an authorized HTTPS CORS-enabled Internet feed (advanced) without USB. A paired readsb bridge remains optional for Firefox/Safari or professional receiver features. The built-in IntelSky browser source covers a limited set of military/government contacts and may have no aircraft in your search region; it is NOT a full general ADS-B network. General ADS-B flights can be tried through the labeled community relay; a private owner-hosted HTTPS/CORS relay is recommended for reliable coverage. Real hardware requires exclusive OS USB access.
