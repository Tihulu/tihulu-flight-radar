Checking direct browser USB capability…

No desktop app, Python server or pairing token required. This page reads genuine ADS-B on 1090 MHz and decodes verified messages inside your browser. It stops USB on tab hide/close. If a desktop readsb decoder still owns your single SDR, WebUSB cannot claim it.

USB cannot connect? Check permissions and driver conflicts (no installation) 
The permission check does not open the USB receiver. The separate interface test briefly opens and releases a previously permitted receiver, without RF tuning or sampling.

Verified Pop!_OS / Nooelec 0bda:2838 fix: if readsb is inactive but the USB tree shows Driver=dvb_usb_rtl28xxu, the Linux DVB driver may still own interface 0. See the safe, device-verified release/restore guide. Never assume every PC uses 1-4:1.0. After an explicit unbind, keep the USB plugged in until the browser test; unplugging it may rebind the driver. This website cannot run sudo or modify kernel drivers.
