Install or update Linux desktop

Run as your regular user in a terminal. The same command replaces an earlier pipx installation; it does not install a second app or purge readsb, tar1090, SDR drivers, receiver settings or recordings. Review the installer source before running.

bash -c 'set -o pipefail; curl -fLsS https://raw.githubusercontent.com/Tihulu/tihulu-flight-radar/main/scripts/install-linux.sh | bash'

The installer may ask for sudo to install system dependencies and a narrowly scoped receiver-service rule. It does not start the SDR automatically. Find Tihulu Flight Radar in your applications menu afterward.

Restore legacy 0.3.1

Want your previous stable version back? The old source is pinned to an exact Git commit and remains available independently of future changes to main.

bash -c 'set -euo pipefail; curl -fLsS https://raw.githubusercontent.com/Tihulu/tihulu-flight-radar/main/scripts/popos-version-switch.sh -o "$HOME/tihulu-flight-switch.sh"; bash "$HOME/tihulu-flight-switch.sh" legacy'

Platform options

Pop!_OS / Ubuntu / Debian

One-line installer above. Native Qt window, local readsb receiver, multiple Internet networks and full tar1090.

Windows x64 / macOS Apple Silicon

Portable desktop previews appear as GitHub Actions artifacts when cross-platform builds pass. USB hardware needs an appropriate OS driver and working local decoder.

Browser / GitHub Pages

No installation. Internet ADS-B sources can work without an antenna; direct SDR reception is an optional WebUSB path on supported browsers.

Real data, identifiable sources

Internet-only planes are marked I, physically received ADS-B planes R, and matched planes I/R. Matching ICAO24 records are displayed once. API quotas, browser CORS policies and receiver availability can limit coverage; the app never fabricates aircraft.
